# Return Vending Machine Firmware Reconstruction

## Overview

This repository contains the reconstruction of the original STM32F103RETx firmware used in a Return Vending Machine (RVM).

The project is based on reverse engineering of the original binary and rebuilds the firmware using a clean, modular architecture.

---

## Features

- STM32F103RETx
- FreeRTOS
- UART DMA Circular Reception
- Android Communication Protocol
- CRC16 Modbus
- Packet Builder
- Packet Parser
- Command Registry
- Driver Layer
- Service Layer
- Flash Configuration
- Hardware Abstraction
- Reverse Engineering Documentation
